# 🎓 University Information and Application System

A modern web-based platform designed to provide university-related information and simplify student application processes.

## 🌐 Live Demo
[Visit Live Website](https://universityinformationandapplicationsystem.ai.studio/)

## 📌 Project Overview
The University Information and Application System is designed to make university information easily accessible through a user-friendly web interface. It aims to improve communication between students and university administration by providing a centralized platform for important information and application-related services.

## ✨ Features
- User-friendly interface
- University information management
- Student application support
- Easy navigation
- Responsive web design
- Modern and interactive UI

## 🛠️ Technologies Used
- React.js
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- Google Gemini API

## 🚀 Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**
```bash
git clone https://github.com/nadiyakaiyum-jpg/university-information-and-application-system.git
```

**2. Navigate to the project folder**
```bash
cd university-information-and-application-system
```

**3. Install dependencies**
```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file and add your Gemini API key if required:

```env
GEMINI_API_KEY=your_api_key_here
```

**5. Start the development server**
```bash
npm run dev
```

Open the local URL shown in your terminal.
